## 与 IMPC 标准的关系

- **IMPC 方案的表述**：自动追踪时，以小鼠**中心点进入新臂区域**判定
  一次入臂。IMPC 原文没有规定 20% 入臂深度、0.12 秒确认时间，
  也没有规定缺失/未知区域、直接换臂、臂/中心边界抖动等边界处理；
  本软件按 IMPC 的中心点判定实现，未引入上述额外条件。
- **边界处理的可执行细化**（为可重复执行而明确）：
  - 首个中心点处于新区域的有效观测即记一次，不要求额外深度或确认
    时间；事件时间与确认时间取该次有效观测的源时间；
  - 缺失、无效或未知区域不构成入臂、不制造离臂/重入（中性）；
  - 直接换臂（A→B 等）按区域转换计，不强制经过中心；
  - 臂/中心边界反复切换按观测转换计数（**无时间防抖**）；
  - 交替率沿用既有公式：连续三个不同臂、机会数 N−2。

## 比对（小鼠 1，机算 vs 人工）

方法：编辑距离（Levenshtein）及逐段对齐（`difflib.SequenceMatcher`
交叉核对），并按"连续相同臂合并"给出交替率对照。

### 视频 14.55.56（run `9d4c4c02`）

| 指标 | 机算 | 人工 |
| --- | --- | --- |
| 长度 | 41 | 38 |
| A / B / C | 11 / 15 / 15 | 11 / 14 / 13 |

- 编辑距离 **3**，且全部可由**插入**解释（无删除/替换）：
  机算在第 12、16、26 位附近各多 1 次（C、C、B），即人工漏记 3 次；
- 归一化差异率 **7.32%**（3/41），相似率 **92.68%**（SequenceMatcher
  96.20%）；
- 连续同臂合并后：机算 38 段、交替 23、率 **63.89%**；人工 37 段、
  交替 22、率 **62.86%**（差 1.03 个百分点）。

## 怎么读这些数字

- 两段视频的差异**全部是"自动多出"**：机算序列按人工序列插入若干
  单次入臂即可完全复现，没有认错臂、没有顺序颠倒；一致部分逐字符
  相同。
- 结合"人工有时会漏和多"的性质，多出的入臂**经核实为人工漏记**，
  而非自动误判；如需归因到帧级证据，可对照 run 目录的
  `arm_entries.csv`（每次入臂的时间与帧号）逐条复核。
- 交替率对个别漏记不敏感（两段视频分别只差 1.03 / 1.35 个百分点）。
- 检测率/准确率的严格标定仍属"独立动物精度"路线（未执行）。
